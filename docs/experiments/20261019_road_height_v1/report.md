# 路面高度 v1 实验分析

结论：原轨迹指标略好，横移视角没有观察到一致改善；但这轮实验的 SDF 高度网络与辅助颜色网络都没有训练，不能用来判断可学习路面高度的价值。根因是本次实现新增的训练入口被同类中后面的旧方法覆盖，属于实现遗漏。

## 对比范围

- 新版：`20261019_lidar+traincam2_3_5_9_12_0_1_6_7_10_11sdf-heightv1`。
- 基线：`20260919_lidar+traincam2_3_5_9_12_0_1_6_7_10_11soft-road-bg-suppression`。
- 两组均取 `group0/checkpoint_final.pth`，40000 步，相机 2、3、5、9、12，99 帧，共 495 张图。
- 基线根目录的 JSON 是 group0/group1 合并结果，新版只有 group0；直接比较根目录汇总会混淆相机范围。本报告使用各自 group0 的评估 JSON。
- 495 对导出的 GT 像素逐一完全相同，保存的 group0 配置除输出路径、新增高度场和其优化器外一致。
- 配置 `test_image_stride=0`，这些原轨迹指标是已有观测的重建质量，不是留出视角泛化指标。

| SSIM ↑，原评估 JSON | 0.85050 | 0.85396 | +0.00346 |
| LPIPS ↓，原评估 JSON | 0.24660 | 0.24110 | −0.00551，约 −2.23% |

路面 PSNR 使用原分割 mask 且排除自车，在有效路面像素上计算每张图 MSE，再转换 PSNR 并等权平均；没有用整图补零的方式计算。非路面指标同样排除自车。PNG 是量化后的结果，所以不能将其 PSNR 数值与浮点渲染的原评估 JSON 混作同一口径。

| 2 | 26.88178 | 27.07724 | +0.19546 |

原轨迹的第 50 帧可见：两组均能保持主要标线走向，但沥青细节、细标线边缘和侧方区域仍有模糊。未发现足以支撑几何明显改善的一致现象。

## 左移 3 米视角

检查相同文件名的 5 个相机第 50 帧，以及相机 2 的第 0、50、98 帧：

- 第 0 帧，近处路面和标线在两组中都有明显拉伸、涂抹，新版未消除。
- 第 50 帧，新版局部沥青纹理更平滑，但中心标线模糊仍在；平滑本身不能说明几何更真实。
- 第 98 帧，两组均存在明显路面碎裂、带状伪影和远处车辆附近的不完整表达。
- 侧方相机的近地纹理拖影仍然存在，没有观察到跨相机一致的改善。

这些是抽样的静态视觉判断，不是全序列时间稳定性评估。新视角没有配对真实 GT，也没有保存的独立几何测量，因此不计算该视角的真实 PSNR 或宣称高度精度提高。目录均标为 `left_shift_3m_step40000`，但目录名本身不是相机矩阵完全一致的证明。

## 核心诊断：网络没有发生学习

证据来自实际 checkpoint 与运行时备份，不依赖当前工作区代码：

1. 新版 `group0/metrics.json` 共 41 条记录，只有 `RoadNodes#surface_field` 学习率，没有任何 `road_field_rgb/lidar/eikonal/coverage` 损失和高度诊断指标。
2. 最终 checkpoint 的 `surface_field.geometry.2.weight` 和 `bias` 全为零，高度残差严格为零。
3. 根据运行配置和固定种子 2718 重建初始化网络，逐个参数比较：几何编码、几何 MLP、颜色编码、颜色 MLP **全部与初始化逐元素完全相同**。
4. 运行备份中的 `models/trainers/scene_graph.py` 第 110 行接入新 `compute_losses`，但第 530 行再次定义同名方法，后者覆盖前者，只调用父类旧损失。`compute_metrics` 也存在相同问题。

优化器注册了参数组并不意味着损失真的接入训练。这次 CPU 单元测试验证了独立模块，却没有验证完整训练器实际调用的入口，未能及时发现该集成错误。

这不是“高度学习没有收益”，而是“高度学习没有执行”。最终高斯的颜色仍由原训练流程正常优化；未训练的是新增辅助颜色网络。

## 那路面为什么仍有变化？

两组 RoadNodes 都是 1,490,106 个，XY 逐元素完全相同。Z 的差异为：

| 高度变化统计 | 数值 |
| --- | ---: |
| 平均有符号变化 | −0.053 cm |
| 平均绝对变化 | 0.584 cm |
| 绝对变化中位数 | 0.378 cm |
| 绝对变化 P95 | 1.824 cm |
| 绝对变化 P99 | 3.127 cm |
| 最大绝对变化 | 14.015 cm |
| 变化超过 1 cm 的点 | 17.66% |
| 变化超过 5 cm 的点 | 0.141% |

由于学习残差为零，这些变化来自原点高度转成 H₀ 网格后再插值查询，而非训练出的高度修正。Background 还从原来的高度先验切换为新高度场的查询方式，其支撑范围与插值也随之变化。两者会影响后续颜色优化和 Background 增密，因此最终图像不必完全相同。

Background 数量从 1,066,205 变为 1,074,796（约 +0.81%）；RoadNodes 数量不变。不能把图像差异单独归因于“高度网格平滑”，因为 Background 的判定变化及其训练下游效应也同时存在。

## 成本与下一步

训练日志记录的循环总耗时从 1:57:35 增加到 3:00:15，约 +53.3%。这是两次运行的实际观察，不是同机同负载的性能基准；即使辅助分支未训练，重复高度同步和 Background 网络查询仍会引入额外工作。

下一步应先合并重复的训练器方法，再做短程验证，确认真实入口产生 SDF 损失、几何与辅助颜色参数发生更新、Z 的学习残差非零，并检查射线有效比例和高度变化上限，再运行完整训练。无需新增对照训练，可以继续以用户已有基线作效果对比；但严格因果分析时仍需区分 H₀ 重采样和可学习残差的贡献。

本次分析未修改训练实现，未重跑训练，也未修改原实验输出。
