# 路面高度 v2 结果分析

结论：SDF 训练已生效，原轨迹外观小幅提升；尚未达到“高度更准确、横移标线明显更稳定”的预期。

## 对比口径

对比 20260919 soft-road-bg-suppression 的 group0 与本次 sdf-heightv2 的 group0，均为 40000 步、相机 2/3/5/9/12、99 帧，共 495 张。逐张 GT 像素完全相同；保存配置仅输出路径、新增高度场和优化器不同。基线根目录是多组汇总，不能直接比较。test_image_stride=0，原轨迹是观测重建质量。代码快照差异见 summary.json，配置相同不代表只有高度残差一个变量变化。

## 原轨迹

| 指标 | 基线 | v1 | v2 |
| --- | ---: | ---: | ---: |
| 官方 PSNR ↑ | 29.20169 | 29.31544 | 29.43404 |
| 官方 SSIM ↑ | 0.85050 | 0.85396 | 0.86182 |
| 官方 LPIPS ↓ | 0.24660 | 0.24110 | 0.23300 |
| 路面 PNG PSNR ↑ | 28.81475 | 28.89558 | 28.93675 |

v2 相比基线：PSNR +0.23235 dB、SSIM +0.01132、LPIPS 降低 5.52%；路面仅 +0.12200 dB，非路面 +0.37946 dB。路面计算排除自车，在 mask 内直接求 MSE，不补零；PNG 与官方浮点指标口径不同。

路面分相机变化：2 +0.47361、3 +0.32902、5 −0.12086、9 −0.12276、12 +0.05101 dB。53.74% 样本改善，变化中位数 +0.05933 dB，收益较弱且不均匀。相比 v1，路面均值仅 +0.04117 dB。单次训练未验证可重复性。

## 是否达到几何预期

- checkpoint 中几何编码/MLP、颜色编码/MLP 全部相对初始化发生更新；日志存在四项 SDF 损失，v1 的入口覆盖问题已不再阻止本轮学习。
- 最终高度对 LiDAR 留出点 MAE 为 2.563 cm，初始网格为 1.605 cm，增加 0.958 cm，约 59.7%。相同点上的平均学习高度残差 1.683 cm。它们参与过初始化，并非独立几何测试集；该结果至少不支持高度精度改善。
- 全部路面高斯 XY 与基线逐元素相同；Z 平均绝对变化 1.985 cm、P95 5.528 cm、P99 16.082 cm；6.07% 的点变化超过 5 cm。这里包含初始网格重采样，不能全归因于学习残差，也不能把变化量当误差。
- 冻结前有效射线比例明显非零、不透明度约 0.99–1，分支在工作；30000 步后分支按配置冻结，末尾射线诊断为零不等于训练失败。冻结后日志中的损失值可能是日志器保留值，不代表仍在优化。

## 左移 3 米观察

抽查五相机第 50 帧，以及相机 2 的 0/50/98 帧：第 50 帧正前方中心标线局部更清楚，但起始帧近处标线涂抹、侧方纹理拖影、末帧带状碎裂仍然明显，未见跨相机一致改善。没有横移真实 GT；这是静态抽样判断，不是全序列稳定性评估，也未核对逐帧相机矩阵完全一致。

## 成本与建议

训练循环日志总耗时：基线 1:57:35，v1 3:00:15，v2 3:30:14；v2 比基线增加约 78.8%，比 v1 增加约 16.6%。这是不同运行的实测，不是受控性能基准。

下一步优先用匹配 fixed-height 对照分离网格重采样与高度学习收益，并在短程实验中调强 LiDAR 锚定或调低几何更新强度，观察高度 MAE 与横移标线是否同时改善。RGB 与 LiDAR 损失的标量大小不足以判断梯度谁主导；“外观目标牺牲几何精度”目前只是与观察相符的假设，需梯度或消融验证。不要优先增加训练步数：当前 30000 步后高度分支已经冻结。

分析只新增本目录的脚本、CSV、JSON 与图片，未修改训练代码或原实验输出。
